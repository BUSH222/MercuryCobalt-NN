# Документация Mercury Cobalt

Документация проекта «Планировщик устойчивости спутниковой группировки»
(кейс «Проектирование устойчивой спутниковой группировки», КосмоХакатон 2026).
Код лежит в [`../../MercuryCobalt-NN`](../../MercuryCobalt-NN).

## Разделы

1. [Обзор и killer-фичи](./features.md) — что делает продукт и чем он
   выделяется.
2. [Архитектура](./architecture.md) — слои фронтенда, стор, откуда берутся
   данные, почему бэкенда почти нет.
3. [Формат данных](./data-format.md) — схема сценария `cosmo-A-1.0` и
   результата расчёта `cosmo-A-result-1.0`.
4. [Алгоритмы](./algorithms.md) — геометрия видимости, маршрутизация (BFS),
   подбор конфигурации на покрытие, видимость по рельефу.
5. [Запуск и деплой](./running.md) — локальная разработка, Docker,
   переменные окружения, terrain-бэкенд.
